# Gameplay screenshots

This folder is reserved for real captures from the running game. No concept art or AI-generated image should be added as evidence of gameplay.

Capture these states from a browser connected to a local or deployed game:

- `lobby-desktop.png` — room code and the selected player cards visible.
- `investigation-desktop.png` — a live investigation location and evidence board.
- `ending-desktop.png` — the post-vote reveal and personalized result.
- Optional `lobby-mobile.png` — narrow-screen layout.

The current isolated workspace could run the Vite app, but its available browser could not reach the workspace's loopback server and no local browser engine was installed. For that reason, no screenshot is included yet; this avoids substituting artwork or mockups for real gameplay captures.
